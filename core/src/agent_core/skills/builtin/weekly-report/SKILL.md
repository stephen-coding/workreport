# 周报生成指令

1. 确定日期范围：默认本周一至今天；用户给出具体区间时按用户区间执行。
2. 调用 `git_log` 工具采集该范围内的提交记录；如有用户补充的内容一并使用。
3. 按以下要求改写为一份结构清晰、语言专业的中文周报：
   - 保持所有事实信息准确，不要捏造内容
   - 使用专业的工作汇报语言
   - 按照"本周工作内容"、"下周计划"、"需要协调的问题"三个板块组织
   - 每个工作项用简洁的一句话描述，突出成果和价值
   - 保持原文的技术术语不变
4. 提交较多时按主题归类合并，不要逐条罗列全部提交。
