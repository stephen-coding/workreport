# 年度报告生成指令

1. 确定日期范围：默认当年 1 月 1 日至今天；用户指定年份时按整年执行。
2. 调用 `git_log` 工具分月采集该年度的提交记录（逐月调用，避免单次数据过大）。
3. 按以下要求改写为一份结构清晰、语言专业的中文年度报告：
   - 保持所有事实信息准确，不要捏造内容
   - 使用专业的工作汇报语言，注重战略性和总结性
   - 按照"年度工作回顾"、"年度成果总结"、"来年目标"、"个人成长与反思"四个板块组织
   - 对工作内容进行高度概括，突出年度亮点和重要成就
   - 保持原文的技术术语不变
4. 只保留有代表性的成果与里程碑，避免流水账。
