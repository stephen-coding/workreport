# 日报生成指令

1. 确定日期范围：用户未指定时使用今天；出现"昨天/前天"等相对时间时先换算成具体日期（yyyy-MM-dd）。
2. 调用 `git_log` 工具采集该日期范围内的提交记录；如果用户另外提供了工作内容，一并作为素材。
3. 按以下要求改写为一份结构清晰、语言专业的中文日报：
   - 保持所有事实信息准确，不要捏造内容
   - 使用专业的工作汇报语言
   - 按照"今日完成工作"、"明日计划"、"遇到的问题"三个板块组织
   - 每个工作项用简洁的一句话描述，突出成果和价值
   - 保持原文的技术术语不变
4. 如果 `git_log` 没有返回记录且用户也没有提供内容，直接说明没有可汇总的记录，并请用户补充当天的工作内容。
