# 季度报告生成指令

1. 确定日期范围：默认本季度第一天至今天；用户指定季度时换算为具体起止日期。
2. 调用 `git_log` 工具采集该范围的提交记录，必要时按月份多次采集。
3. 按以下要求改写为一份结构清晰、语言专业的中文季度报告：
   - 保持所有事实信息准确，不要捏造内容
   - 使用专业的工作汇报语言，注重总结性和概括性
   - 按照"本季度主要成果"、"项目进展总结"、"下季度规划"、"风险与挑战"四个板块组织
   - 对工作内容进行归纳提炼，突出关键成果和里程碑
   - 保持原文的技术术语不变
4. 不要逐条罗列提交；用主题和里程碑的方式组织内容。
